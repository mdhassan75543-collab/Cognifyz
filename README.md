# 🟢 Level 1

## Task 1 – HTML/CSS

The objective of this task was to practice the fundamentals of **HTML and CSS** by creating basic web components.

### Requirements

* Create a simple webpage with:

  * Heading
  * Paragraph
  * Image
* Build a basic form with:

  * Single input field
  * Submit button
* Design and code a simple navigation menu with:

  * Three links

### Technologies Used

* HTML5
* CSS3

---

## Task 2 – JavaScript

The objective of this task was to implement basic **JavaScript functionality and user interactions**.

### Requirements

* Develop a button that changes its color when clicked using JavaScript.
* Create an alert box that displays a greeting message based on the current time.
* Build a basic calculator that:

  * Accepts two numbers
  * Adds the two numbers
  * Displays the result

### Technologies Used

* HTML5
* CSS3
* JavaScript

---

# 🔵 Level 2

## Task 1 – Front-end Frameworks

The objective of this task was to learn and implement **front-end CSS frameworks** for responsive web development.

### Requirements

* Create a responsive card component using a front-end framework such as **Bulma or UIKit**, containing:

  * Image
  * Text
* Implement a basic responsive grid layout using a front-end framework such as **Bootstrap or Foundation**.

### Technologies Used

* HTML5
* CSS3
* Bulma
* Bootstrap

---

## Task 2 – Responsive Design

The objective of this task was to create web interfaces that adapt to different screen sizes.

### Requirements

* Convert a basic webpage into a responsive design using **CSS media queries**.
* Create a mobile-friendly navigation menu.
* Make the navigation menu collapse into a **hamburger menu** on smaller screens.

### Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Media Queries

---

# 🟣 Level 3

## Task 1 – Image Manipulation

The objective of this task was to work with images and create interactive image-based components.

### Requirements

* Create a basic image gallery using CSS with thumbnail images.
* Make the thumbnail images enlarge when clicked.
* Implement a simple image slideshow that automatically transitions between images.

### Technologies Used

* HTML5
* CSS3
* JavaScript
